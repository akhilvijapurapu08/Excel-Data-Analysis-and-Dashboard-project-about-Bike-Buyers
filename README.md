# Bike Buyers Data Analysis Dashboard

## Project Overview
This project is an end-to-end data analysis workflow built entirely in Microsoft Excel. It analyzes the demographics and financial backgrounds of various individuals to uncover trends and patterns regarding who is most likely to purchase a bike.

## Dataset Details
The dataset contains customer information including:
* **Demographics:** Gender, Age, Marital Status, Education, Region
* **Financials/Lifestyle:** Income, Occupation, Home Ownership, Number of Children, Number of Cars, Commute Distance
* **Target Variable:** Purchased Bike (Yes/No)

## Project Structure
The Excel workbook (`prj 01.xlsx`) is divided into four main sheets:
1. **bike_buyers(RAW):** The original, unprocessed dataset.
2. **bike_buyers:** The cleaned and transformed dataset ready for analysis.
3. **pivot tables:** Aggregated data summarizing key metrics (e.g., Average Income by Gender and Purchase Status).
4. **dashboard:** A visual representation of the insights gathered from the pivot tables, allowing for quick, high-level business intelligence.

## Key Insights
* Explored how average income and gender correlate with bike purchases.
* Analyzed the impact of commute distance and age on a customer's likelihood to buy a bike.

## Tools Used
* **Microsoft Excel:** Data Cleaning, Pivot Tables, Data Visualization, and Dashboard creation.
